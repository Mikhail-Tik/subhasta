Read this first in any new session. Do not re-read the chat. Everything durable is here, in git, and in REFRESH.md.

## The product in one line
Subhasta is the art trade’s terminal: a single-file web app (`build/rostrum.html` + `build/img/`) built by `python3 build.py` from `src/`,
with research data generated by `python3 tools/gen_research.py` from `data/research/bundle.json`. British spelling, short declarative
sentences, every figure sourced and flagged V/S/U, never a route around a control, no email sent without the owner’s explicit OK.

## Hard facts to never re-derive
- The published artifact’s frame loads NO external image, fetch or stylesheet (silently). So: live feeds never worked there; NGA
  IIIF pictures never showed; the Eye in the artifact uses only the page’s own files (atlas sheets + the Library’s 221). A real
  website (GitHub Pages) has none of these limits.
- The artifact holds at most 511 files per version (main is at the cap: see REFRESH.md files map). Assets (`asset: true` uploads)
  are a separate store served at `/_blob/<id>`.
- From this container only GitHub (raw/media/objects.githubusercontent.com, git) and the CDNs on the Artifact allowlist are
  reachable; museum APIs/CDNs are refused by the proxy. WebFetch needs a URL from a search result or the user.
- Artifacts: main https://claude.ai/artifact/N6Ev8cTukqjpYRNcaGE2EB, share https://claude.ai/artifact/7eh559aMb6CybnKqCZcei2.
  Capabilities declaration is a full set (see REFRESH.md): comments composer_only; db rules members, members/{self}, board,
  board/{self}, live, kb, gaps, gaps/{self}, pins, pins/{self}, scores, scores/{self}; downloads; sample; user scopes [profile].
- Scheduled tasks: the daily desk (every day 06:43 ET, trig_01UXJh39qqHSfyDArcmUAV2A; was Mon/Thu until 23 Nov) and the monthly refresh
  (trig_0167Qk45G42Tyyrqts5xNW9i). They must not change sharing or capabilities or create artifacts.
- Checks: `npm run check`, `node tools/lint_data.js`, `python3 tools/globals.py`, `timeout 900 node test.js` (jsdom, ~6 min),
